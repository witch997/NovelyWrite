# 分镜生成规范

> 网文分析系统 · 分镜层 ｜ v3.0
> 独立成文自《分镜层定义规范》v0.17 §8；依赖该规范 §3 切镜判据、§4 类型学、§6 功能体系、§7 接口的定义。
> 流程定位：《语料分析》skill 第二步（与句子标注一次 LLM 往返）——最终产出**分镜标注 JSON**（分镜序列 + 内嵌句子分组信息）。
> 格式契约：**以《JSON数据格式参考》§3 为唯一标准**（`dsh/shot-card/v1`），本规范不再重复定义格式，仅引用。
> 变更：v1.1 新增 §6 可疑分镜诊断 → v1.2 诊断改为低优先级兜底 → v1.3 功能并入节拍字段 → v1.4 删除节拍概念 → v1.5 对齐《拆书》skill → v2.0 产出格式改为 JSON → **v3.0 轻标注：删除 syntax/spacetime/pov/focus 四字段；funcs 精简为 10 种纯枚举（多值、无主辅、无实体），任意值可查询**。

## 1. 标注目标

在**句子标注 JSON**基础上（`dsh/sentence-card/v1`，句子序列——仅切分结构，轻标注无类型/功能），按切镜判据将章节切分为**有序分镜序列**，为每个分镜**直接判定**类型与功能，输出**分镜标注 JSON**（`dsh/shot-card/v1`），供章节层聚合与下游分析。

> **轻标注衔接**：句子层不标注类型/功能（v4.0）；分镜类型/功能由**分镜级直接判定**。

**唯一产出格式**：`dsh/shot-card/v1`（字段定义、约定、示例见《JSON数据格式参考》§3，本规范仅引用）。

## 1.1 输入与输出

| | 内容 | 路径 |
|---|---|---|
| **输入** | 句子标注 JSON（同章，句子序列——仅切分结构） | `store/<语料名>project/句子标注/json/第XXXX章.json` |
| **输出** | 分镜标注 JSON（中间件） | `store/<语料名>project/分镜标注/json/第XXXX章.json`（`dsh/shot-card/v1`） |
| **消费方** | 章节层（聚合生成章节标注） | — |

- 输入边界：句子 JSON 的 `sentenceIds`/`shotId` 为切镜与归属依据
- 输出流向：`shot JSON → 章节层`；分镜 `sentenceRange`/`sentenceIds` 从句子 JSON 按 `shotId` 聚合

## 2. 标注流程（三步）

1. **切分**：按切镜判据（定义规范 §3）切出候选分镜（宁过切、勿合并）
2. **定类型**：按判定优先级（定义规范 §4.3）裁决内容轴主类型；多类命中取优先级最高者
3. **标功能 + 填字段**：标注功能（多值纯枚举，10 种）；给出短标签 `label`（≤10字，无下界，含主语则显式声明）

> 已删除：语法（syntax）、时空锚（spacetime）、视角锚（pov）、焦点主体（focus）——轻标注决策，消费时按需识别。

正常标注无法处理的样本，按 §6 触发**可疑分镜诊断**（低优先级兜底，可自动执行）；诊断不覆盖正常标注，仅供裁定。

## 3. 标注格式（JSON 唯一）

**格式契约**：`dsh/shot-card/v1`（《JSON数据格式参考》§3）。核心字段：

| 字段 | 说明 |
|---|---|
| `schema` | `dsh/shot-card/v1` |
| `chapter` | {number, title, range} |
| `source` | 源句子标注 JSON 路径 |
| `shots[]` | 分镜数组（按 id 升序） |
| `shots[].id` | 分镜序号 |
| `shots[].type` | 内容轴六型（信息/对话/心理/动作/事件/环境） |
| `shots[].funcs` | **多值纯枚举**（10 种）；无主辅、无实体、无顺序 |
| `shots[].label` | 短标签（≤10字，无下界，含主语则显式声明） |
| `shots[].sentenceRange` | 本镜句子 seq 区间 [start,end]（脚本聚合） |
| `shots[].sentenceIds` | 展开的 S# 列表（与区间一致，脚本聚合） |
| `shots[].note` | 仅承载存疑说明（诊断信号不在此字段） |

**字段约定**（对齐《JSON数据格式参考》§2/§3）：
- **funcs 多值无主辅**：不引入 role/主辅字段，funcs 为平等多值数组 `["推进", "塑造人物"]`；任意值可查询到该分镜；无实体（纯枚举）。
- **句子归属**：`sentenceRange`/`sentenceIds` 从句子 JSON 按 `shotId` 聚合生成；与区间一致（schema 校验）。
- **note 语义收窄**：仅承载标注存疑；诊断信号（§6）由校验/诊断层产出，不写入分镜 JSON。

## 4. 标注规则

- **无遗漏**：原文每个字符必须归属且仅归属一个分镜
- **一致性**：同一标注者对同一文本重复标注，切分边界与标签须稳定一致
- **存疑透明**：无法按判据或优先级唯一确定的样本，先按 §6 诊断信号辅助裁定；仍无法定论的标记疑点并写入 `note`，进入边界问题清单
- **章末校验**：章节最后一镜**按实际功能标注，不强制"悬念"**——真实收尾/日常就标对应功能；确实以悬念收尾才标"悬念"（悬念不再作为章节必需属性，避免强制导致结尾套路化）

## 5. 标注产物

- **分镜标注 JSON**（中间件→最终产出）：`store/<语料名>project/分镜标注/json/第XXXX章.json`，格式 `dsh/shot-card/v1`；`shots[]` 节点含 id/type/funcs/label/sentenceRange/sentenceIds；句子节点经 `shotId` 关联（定义规范 §7.2）
- **边界问题清单**：标注过程中收集的存疑样本（`note` 字段 + 清单），作为切镜判据与类型学修订的输入

## 6. 可疑分镜诊断

**定位：低优先级兜底。** 正常标注流程（§2 三步 + §4 规则）能唯一确定的样本，一律按正常流程处理，不进入诊断；**仅当正常标注无法处理**（判据或优先级无法唯一确定、标签与文本明显冲突且无规则可依）时，才触发诊断信号，供人工裁定。诊断结果不覆盖正常标注结果，仅作为裁定依据；裁定仍无法定论的，进入边界问题清单（§4）。**诊断结果不写入分镜 JSON**（由校验/诊断层单独产出）。

**信号为可开放类型。** 信号定义：`信号{编号, 类别, 触发条件, 处理建议}`；下表为内置信号，类别不设上限，可按需注册新信号（登记触发条件与处理建议），新信号不得与既有信号矛盾。

### 6.1 内置信号：类型 × 功能冲突

| # | 触发条件 | 处理建议 |
|---|---|---|
| 1 | 环境分镜×爆发 | 复核类型或功能标签，二者必有其一矛盾 |
| 2 | 信息分镜×悬念 | 复核悬念标签（信息直给为快节奏机制） |
| 3 | 事件分镜×铺垫 | 复核是否漏标推进（事态变化自带推进属性） |

### 6.2 内置信号：序列模式

| # | 触发条件 | 处理建议 |
|---|---|---|
| 4 | 连续 5 镜无推进/爆发 | 复核是否漏标推进，或标记低价值段 |
| 5 | 连续 3 镜同类型 | 复核切分或类型 |

### 6.3 内置信号：标签自洽

| # | 触发条件 | 处理建议 |
|---|---|---|
| 7 | funcs 为空 | 补标功能（每镜至少一个） |
| 8 | funcs 含重复值 | 去重 |

### 6.4 输出

可疑分镜清单：`{分镜id, 信号编号, 触发说明, 裁定结果}`，低优先级——仅记录裁定过程，不影响正常标注结果；无法裁定的样本进入边界问题清单。
